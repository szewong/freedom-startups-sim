What you are looking at
  • The match engine is reward-blind — it never sees a threshold. Anything that diverges does so through selection, not through a rule written into the physics.
  • Both leagues start from an identical population each restart, so any gap you see opened up during the run.
  • Which number to watch? Two, because they answer different questions. Real capability is absolute — expected points against a fixed neutral team, counting both offense and defense — so it tells you whether a population is getting better at the game at all. B’s win rate against A is relative and zero-sum, so it tells you who is ahead but cannot distinguish “both improved” from “both declined”. Neither sees fatigue: both are fresh-legs measures, and League B’s real weakness shows up most in deep tournament runs.
  • Price of volatility is the parameter that decides whether a high bar degrades real skill or merely adds noise. Set it low and watch League B trade capability away; set it high and the skill gap closes while the volatility gap survives.
  • One run is one sample. The published figures average 16 replicates — a single run here will wander further than those confidence intervals suggest.
